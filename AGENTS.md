# For coding agents: build Afterplate

Goal: a working `Afterplate.app` built from this source on the user's Mac. Run the steps in order. After each step, check its **Done when** before going on. The human version, with reasons, is [docs/build.md](docs/build.md).

## Rules

- Ask the user before `sudo`, before installing Xcode, and before anything that needs their password.
- Never put the user's API keys or passwords in files or commands. The app asks for them in its own Settings.
- Don't edit the source to make a step pass. If a step fails, check **If it fails**, then tell the user what happened.
- The source must not be in an iCloud-synced folder (`~/Documents`, `~/Desktop`): codesign refuses the bundle there.

## Steps

### 1. Tools

```bash
sw_vers -productVersion
xcodebuild -version
command -v brew xcodegen uv git
```

**Done when** macOS is 14 or later, `xcodebuild -version` prints an Xcode version, and all four tools have a path.
**If it fails**:
- No Xcode: ask the user to install it from the App Store and open it once.
- Xcode installed but `xcodebuild` errors: ask before running `sudo xcode-select -s /Applications/Xcode.app`.
- No Homebrew: give the user the install line from https://brew.sh. It needs their password.
- Missing tools: `brew install xcodegen uv git`.

### 2. Source

```bash
mkdir -p ~/Developer && cd ~/Developer
git clone https://github.com/jinsu35/afterplate.git
cd afterplate
```

**Done when** `mac/project.yml` exists.

### 3. Photo model (optional; do it unless the user says not to)

```bash
mac/model/get-model.sh
```

**Done when** the last line reads `saved …/SigLIPImage.mlpackage; prompt embeddings match the model: 1.0000` and `mac/Afterplate/SigLIPImage.mlpackage` exists.
**If it fails**: network errors, run it again. It downloads about 800MB. Skipping this step is allowed: the app builds and runs without the model, with weaker photo sorting. Tell the user if you skip it.

### 4. Build

```bash
cd mac
xcodegen generate
xcodebuild -project Afterplate.xcodeproj -scheme Afterplate -configuration Release \
  -derivedDataPath ~/Library/Developer/Afterplate build 2>&1 | grep -E "error:|BUILD (SUCCEEDED|FAILED)"
```

**Done when** it prints `** BUILD SUCCEEDED **` and `~/Library/Developer/Afterplate/Build/Products/Release/Afterplate.app` exists.
**If it fails**:
- "resource fork, Finder information, or similar detritus not allowed": the source is in an iCloud folder. Move it to `~/Developer` and rebuild.
- Other `error:` lines: report them to the user as they are.

### 5. Hand over

Tell the user:
- where `Afterplate.app` is;
- to drag it into Applications and open it the first time with right-click › **Open**;
- to allow Photos access;
- to pick an AI (ChatGPT or Grok on a paid plan, or a Claude API key).

The build is signed ad hoc, so macOS asks for Photos access again after every rebuild. That is expected.

## Facts that save time

- `mac/Afterplate.xcodeproj` is generated by `xcodegen generate` from `mac/project.yml`. It is not checked in.
- `mac/Signing.local.xcconfig` (optional, not checked in) can name a development certificate: `CODE_SIGN_IDENTITY = Apple Development: Name (TEAMID)`.
- `mac/run.sh` does a Debug build and opens it, a quicker loop than step 4 while working on the code.
